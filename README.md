# Video Remote

iPadで再生している動画を、iPhoneからリモート操作するWebアプリです。
再生画面（iPad）には映像だけが表示され、シークバーや操作ボタンは一切出ません。

- サーバー不要。2台の端末を直接つなぎます（WebRTC）
- 一度開けばオフラインでも使えます（PWA）
- 動画はiPadの中だけで再生され、どこにも送信されません

## できること（iPhone側）

- 複数の動画をリストにして、順番に再生（連続再生）
- リストから動画を選んで頭出し、前の動画／次の動画
- ループ（オフ／1本／全体）
- 再生／一時停止
- スライダーで再生位置を自由に移動
- ±10秒・±1秒・±0.1秒の移動、先頭へ戻る
- 時刻を指定して移動（例：`1:23.5`）
- 暗転（映像をフェードアウトして黒画面に）、消音
- 再生速度（0.5× / 1× / 1.5× / 2×）

## ファイル構成

フォルダはありません。次の6つのファイルをすべて、リポジトリの一番上に置いてください。

- `index.html`（アプリ本体）
- `sw.js`（オフライン用）
- `manifest.webmanifest`（ホーム画面用の設定）
- `icon-512.png`
- `apple-touch-icon.png`
- `README.md`（この説明）

## 公開方法（GitHub Pages）

iPhoneのSafariからでも操作できます。

1. GitHubで新しいリポジトリを作ります（Public）。
2. 「Add file → Upload files」から、上の6つのファイルをまとめて選んでアップロードし、「Commit changes」を押します。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
5. 数分後に表示されるURL（`https://ユーザー名.github.io/リポジトリ名/`）が、このアプリのアドレスです。

## 端末への準備（最初の1回だけ・要インターネット）

iPadとiPhoneの両方で行います。

1. SafariでアプリのURLを開きます。
2. 共有ボタン →「ホーム画面に追加」を選びます。
3. ホーム画面のアイコンから一度起動し、「オフラインでも使える状態になっています」と表示されることを確認します。

以降はホーム画面のアイコンから起動すれば、インターネットなしで使えます。
ホーム画面から起動すると、Safariのアドレスバーも表示されません。

## 使い方

### 1. 2台を同じネットワークにつなぐ

次のどれかでつなぎます。インターネットへの接続は必要ありません。

- **iPhoneの「インターネット共有」にiPadをつなぐ**（外出先向け）
  iPhoneで「設定 → インターネット共有」をオンにし、iPadのWi-Fi一覧からiPhoneを選びます。Bluetooth経由でも接続できますが、Wi-Fi経由のほうが安定します。
- 同じWi-Fiルーターにつなぐ（ルーターがインターネットにつながっていなくても使えます）

### 2. iPad：動画を選ぶ

アプリを開き「この端末で再生する」→「動画を追加」で動画を選びます（複数可）。
「↑」「↓」で順番を入れ替え、「✕」でリストから外せます。準備ができたら「iPhoneと接続する」を押します。
iPadにQRコードとカメラ映像が表示されます。

### 3. iPhone：iPadのQRコードを読み取る

アプリを開き「この端末でリモコン操作する」→ iPadのQRコードをカメラで読み取ります。
iPhoneに新しいQRコードが表示されます。

### 4. iPad：iPhoneのQRコードを読み取る

iPhoneの画面をiPadのカメラに映します。接続されると、iPadは真っ黒な再生画面に切り替わり、iPhoneにリモコンが表示されます。

カメラが使えない場合は「カメラを使わずに接続する」を開き、「コードを共有（AirDrop）」で送ったコードを貼り付けても接続できます。

### iPadのメニュー

再生画面を **1.5秒長押し** すると、メニュー（接続し直す／動画リストを編集する／最初の画面に戻る）が開きます。普段は何も表示されません。
動画リストの編集中もiPhoneとの接続は切れないので、途中で動画を追加することもできます。

### 複数の動画を続けて再生する

- **連続再生がオン**：1本終わると、自動で次の動画を再生します。
- **連続再生がオフ**：1本終わると、その場で止まります。「次の動画」やリストのタップで次へ進めます。
- **ループ：1本**：今の動画を繰り返します。
- **ループ：全体**：連続再生がオンのとき、最後の動画が終わると最初に戻ります。
- リストの動画をタップすると、その動画の先頭で停止した状態になります。再生ボタンで始めます。
- 「前の動画」は、再生位置が3秒を過ぎていると今の動画の先頭に戻ります。

## 注意点

- **iOS / iPadOS 16.4以降** を推奨します。
- 使用中はiPhoneの画面をロックしないでください。ロックしたりアプリを切り替えたりすると接続が切れることがあります。切れた場合は、iPhoneの「接続」とiPadの長押しメニューから接続し直します。
- iPadの時計・バッテリー表示（ステータスバー）は、Webアプリの仕様上消せない場合があります。
- 動画はアプリを開くたびに選び直します。
- 動画が切り替わる瞬間は、一瞬黒い画面になります。
- iPadで「自動再生がブロックされた」とiPhoneに表示されたら、iPadの画面を1回タップしてください。
- Bluetooth経由のインターネット共有では、端末の組み合わせによって接続できないことがあります。その場合はWi-Fi経由で試してください。

## ファイルを更新したとき

`sw.js` の `VERSION` を `v3` などに変えてからアップロードすると、各端末のオフライン用キャッシュが新しくなります（アプリを一度開き直すと反映されます）。
